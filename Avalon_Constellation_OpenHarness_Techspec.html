Avalon Constellation update

PT-Storage solar systems and optional OpenHarness frameworks across machines.

Installed and checked on owner laptopRevision 1.0 · 7 November 2026Owner: Ed / ProgreTech
01 / Purpose and scope

Purpose and scope

Avalon’s Constellation appearance shows PT-Storage project folders as solar systems and can display the latest active agent frameworks recorded by OpenHarness across machines. Ed requested this update on 7 November 2026. This specification records the implemented behavior and its checks.

When available, the immediate directories inside /mnt/PT-Storage/Projects supply the solar systems. The installed laptop currently displays development, production and quality. Saved manual folders remain available when the shared directory is unavailable or its option is off.

The optional OpenHarness integration replaces local configured agent identities with distinct frameworks, ordered by their newest recorded activity. The default count is five. It does not change Avalon’s selected reasoning model or conversation.

02 / Interfaces and behavior

Interfaces and behavior

GET /api/constellation/sources returns settings, their revision, the local agent roster, a separate framework list, collector availability, refresh state and a status notice. Each framework entry exposes its name, machine, state and activity timestamp.

POST /api/constellation/sources accepts the existing refresh action or {action: "save", revision, settings}. Saves require the current revision and the exact settings keys; invalid settings or stale revisions are rejected. Existing authentication, origin and CSRF checks apply.

Folder and session rules

Directory enumeration is one level deep. Hidden, sensitive and linked directories are excluded through the existing resource path checks. The collector accepts at most twelve systems. More eligible folders cause an error; users can disable automatic subfolders and choose manual roots.

Sessions need a nonempty framework name of at most 80 characters and a parseable timestamp with a timezone. Timestamp ordering uses actual instants, including timezone offsets. Framework names are deduplicated case-insensitively. Stable hashed IDs separate framework display nodes from local identity nodes.

Avalon scene and existing renderersFramework nodes and session-context targets → browser preview and GNOME wallpaper

galaxy_sources.py owns preferences, collector configuration, filtering and periodic publication. It recognizes both the original constellation sibling and the staged pt-constellation-factory-alt-dev sibling. harness_constellation.py gathers metadata and adds framework nodes after normal agent nodes have been removed.

The existing two-minute collector rebuild remains in place. Between rebuilds, the publication loop checks metadata at roughly ten-second intervals plus query time. Machine session queries use at most four concurrent workers. Each CLI call has a twelve-second timeout; there is no single aggregate deadline.

For every displayed framework, its latest reported session folder is matched to the longest visible solar-system path. Matching does not require that remote folder to exist locally. A matching root becomes a context target; frameworks outside visible systems keep their ordinary orbit. Write targets and modified targets remain empty. Historical memory authors are preserved.

Resumen operativo

Avalon usa las subcarpetas inmediatas de /mnt/PT-Storage/Projects como sistemas solares cuando están disponibles. La integración opcional con OpenHarness sustituye los agentes locales por los frameworks con actividad más reciente en las máquinas de la cuenta. El límite inicial es cinco y se puede cambiar de 1 a 100. Cada framework aparece una sola vez; el movimiento indica el contexto de la sesión, sin afirmar que se hayan modificado archivos. Al desactivar las opciones se recuperan las selecciones locales guardadas. Se superaron 22 pruebas de backend y las comprobaciones de interfaz a 1280 y 390 píxeles. Dos máquinas estaban desconectadas; no se verificó su actividad real.

運用概要

Avalon は、利用可能な場合に /mnt/PT-Storage/Projects の直下のフォルダーを太陽系として表示します。任意の OpenHarness 連携を有効にすると、ローカルのエージェント表示が、アカウント内の各マシンで最近活動したフレームワークの表示に切り替わります。初期値は5件で、1〜100件に変更できます。同じフレームワークは最新のセッションに基づいて1回だけ表示します。移動はセッションの作業場所を示し、ファイルの変更を証明するものではありません。連携を無効にすると保存済みのローカル設定に戻ります。バックエンド22件のテストと、幅1280・390ピクセルの画面検証に合格しました。2台はオフラインで、実際の活動は未検証です。
