# Project Avalon

An embodied digital robot for Ubuntu: a living wallpaper and Presence Control Center, powered by LampOS and one selected AI runtime/model.

**Status:** specification and feasibility research. No Avalon application, installer or live LampOS integration has been delivered yet.

- [Product specification](docs/SPECIFICATION.md) — authoritative requirements, architecture and acceptance criteria.
- [Five-phase delivery plan](docs/DELIVERY.md) — dependencies, exit gates and honest progress.
- [Verified findings](docs/RESEARCH.md) — upstream revision, workstation observations and unresolved integration work.
- [Asset provenance](docs/ASSETS.md).

The owner-supplied [concept image](wide_cinematic_poster_mockup_layout_of_a_desktop.png) is the visual target. The original [HTML concept/charter](ProgreTech_Presence_Concept_Charter.html) is preserved as historical reference; its Open WebUI, multiple-agent and simulated-interface assumptions are superseded by the specification.

No phase is complete merely because its interface is drawn. Runtime states, device access, model selection, permissions and wallpaper exclusivity must pass their delivery gates.
