# Project Avalon

An embodied digital robot for Ubuntu: a living wallpaper and Presence Control Center, powered by LampOS and one selected AI runtime/model.

**Status:** phase 2 adds the authenticated Presence Control Center: installed Ollama discovery, local OpenCode chat, saved conversations, serialized switching, stop and native file-access controls. Full avatar production, voice and vision remain phases 3–4. See [phase 2 qualification](docs/PHASE-2.md) for checks and platform blockers.

[Phase 1 setup and evidence](docs/PHASE-1.md). The installed **Project Avalon** app-menu/Desktop launcher opens the Presence Control Center. Log out/in once to load newly installed GNOME extension code.
